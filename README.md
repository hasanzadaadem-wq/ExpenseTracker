
# 💰 Expense Tracker

## 📌 About the Project

Expense Tracker is a simple and user-friendly application designed to help users manage their personal finances. It allows users to track their income and expenses, monitor their spending habits, and maintain better control over their budget.

## ✨ Features

- Add new income and expense records.
- View all financial transactions.
- Track total income and expenses.
- Calculate current balance.
- Manage personal budget.
